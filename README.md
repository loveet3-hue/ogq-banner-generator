# OGQ 콘텐츠 생성기 (배너 + 인터뷰 카드뉴스)

> **🌐 웹에서 바로 사용: https://ogq-banner.streamlit.app** (설치 없음, Windows/Mac 모두 가능)

두 가지 도구가 하나의 웹앱에 들어 있습니다:
- **🖼 배너 생성기** — OGQ마켓 판매 링크 또는 스티커 원본(zip) → 전 플랫폼 배너 9종 + SNS 출시 홍보 이미지 2종
- **📰 인터뷰 카드뉴스** — 네이버 폼 인터뷰 응답 엑셀(.xlsx) → 인스타 카드뉴스(표지+Q&A) + 캡션 + 블로그 글 (`cardnews/` 엔진, Playwright 렌더링)
실행할 때마다 색상 전략·배경 패턴·장식·레이아웃이 랜덤 조합되어 **매번 다른 디자인**으로 생성됩니다.

> 처음 쓰시는 분은 **「처음 사용하는 분 필독.txt」** 를 먼저 읽어주세요.
> 배포는 Drive의 **「OGQ 배너 생성기.zip」** 으로 합니다 (폴더째 다운로드하면 Drive가 실행 권한을 지워 앱이 안 열림).
> 코드를 수정한 뒤에는 `zsh build/make_zip.sh` 로 zip을 다시 만들어 Drive에 올려주세요.

## ✏️ 편집 기능 (웹)
생성 후 「배너 편집」에서 배너를 고르면 브라우저 안에서 바로 수정할 수 있습니다:
스티커 드래그 이동 · 크기/회전 · 삭제 · 복제 · 좌우반전 · 맨앞/맨뒤, 팩의 다른 스티커 추가,
**✂ 자르기**(스티커의 일부 영역만 남김 — 글자 제거 등), **◌ 지우개**(문질러 부분 삭제), 실행취소,
텍스트 추가/더블클릭 수정(폰트·색·테두리), 배경색 변경 → **PNG 다운로드** (원본 해상도).

## 소스 전달 방법 2가지
1. **링크** — OGQ마켓 판매 페이지 URL 붙여넣기 (스티커 이미지를 자동 다운로드)
2. **원본 파일** — 스티커 원본 zip(main/tab/1~24.png 패키지)이나 이미지 폴더를 끌어다 놓기

## 사용법 (웹 — 권장)

`web_app.py`를 Streamlit으로 띄우면 URL 접속만으로 사용할 수 있습니다 (설치·보안창 없음, Windows도 가능).

```bash
pip install -r requirements.txt
streamlit run web_app.py
```
호스팅: GitHub 저장소 연결 후 [Streamlit Community Cloud](https://share.streamlit.io) 에서 무료 배포 가능 (Python 3.11 권장).

## 사용법 (더블클릭)

폴더 안의 **「배너 생성기.app」을 더블클릭** → 링크를 붙여넣거나 zip 파일을 창에 끌어다 놓고 Enter.
끝나면 결과 폴더가 자동으로 열리고, Google Drive 데스크톱 앱이 있으면 `Ai개발/<작품명> 배너/`에도 자동 저장됩니다.

## 사용법 (터미널)

```bash
# 링크로
python3 banner_gen.py "https://ogqmarket.naver.com/artworks/sticker/detail?artworkId=61bc52a6358f4"

# artworkId만
python3 banner_gen.py 61bc52a6358f4

# 스티커 원본 zip / 이미지 폴더
python3 banner_gen.py ~/Downloads/깡지라네13.zip

# 시안 3개 한번에 (시안_1, 시안_2, 시안_3 폴더)
python3 banner_gen.py 61bc52a6358f4 --variants 3

# 출력 폴더 지정 / 디자인 고정(재현) / Drive 복사 끄기
python3 banner_gen.py 61bc52a6358f4 --out ./배너 --seed 42 --no-drive
```

## 필요 환경
- Mac + Python 3 (없으면 앱이 설치 안내를 띄웁니다)
- `Pillow`, `requests` — 첫 실행 시 자동 설치
- 한글 폰트: Pretendard 권장(`~/Library/Fonts`), 없으면 Apple SD Gothic Neo (텍스트 옵션 사용 시에만 필요)

## 디자인 원칙 (v3)
- 스티커는 **서로 겹치지 않고, 잘리지 않고**, 크게 · 균등 간격 · 하단 정렬
- 배너당 스티커 1~3개 (많이 넣지 않음)
- 배경은 밝은 파스텔(파스텔·크림·민트·스카이·피치·라벤더·투톤) + 은은한 패턴/블롭 그라데이션
- 장식은 배너당 1~2색으로 통일, 빈 공간에 2~5개만
- 구도: 나열(2~3) · 히어로+서브 · 솔로 · 히어로 강조 나열 · 모서리(랜딩) — 실행마다 랜덤

## 디자인 가이드 반영
- 배경 순백(#FFFFFF) 금지, 테두리/라운딩 없음 (NOM·SOM 공통)
- 스튜디오 대시보드 PC(1440x180): 왼쪽 ~58%는 텍스트 영역으로 비움, 오른쪽에 스티커 2~3개
- 스튜디오 대시보드 MO(350x200): 왼쪽 절반 텍스트 영역으로 비움
- 스튜디오 랜딩(1020x680 / 660x440): 가운데 텍스트 영역 비움, 좌·우 하단 모서리에만 스티커
- NOM 상단 배너: 카피 문구 없이 이미지만 (카피는 어드민에서 입력)
- SOM PC(1344x260): 주요 오브제 중앙 960px 이내, 좌측 텍스트 영역(400px) 오브제 배치 지양
- SOM MO(672x440): 상단 텍스트 영역 비움, 좌/우 10px 단색 + 자연스러운 그라데이션
- SOM 용량 500KB 초과 시 JPG로 자동 변환

OGQ마켓 배너 자동 생성기 — 처음 사용하는 분 안내
=================================================

[준비물] Mac (Windows는 지원하지 않습니다)

1. 다운로드
   Drive의 「OGQ 배너 생성기.zip」 파일 하나를 다운로드하고
   더블클릭해서 압축을 풀어주세요.

   ★ 주의: zip 파일 "하나만" 선택해서 다운로드하세요.
     다른 파일/폴더와 함께 선택해 받으면 Drive가 다시 묶으면서
     실행 권한이 지워져 앱이 열리지 않습니다.
   ★ 그래도 "응용 프로그램을 열 수 없습니다"가 뜨면:
     폴더 안의 「앱이 안 열리면 여기 더블클릭.command」를
     우클릭 → 열기 하면 자동으로 복구됩니다.

2. 실행
   폴더 안의 「배너 생성기.app」(강아지 아이콘)을 더블클릭하세요.

   ★ 처음 실행할 때 "열지 않음 / 악성 코드가 없음을 확인할 수
     없습니다" 경고가 뜨는 것이 정상입니다. (Apple 인증서로 서명하지
     않은 사내 도구라 Mac이 한 번 확인하는 것 — 딱 한 번만 풀면 됩니다)

     ① 경고 창에서 [완료] 클릭 (※ 휴지통으로 이동 아님!)
     ② 애플 메뉴 → 시스템 설정 → 개인정보 보호 및 보안
     ③ 아래로 스크롤 → "'배너 생성기'이(가) 차단되었습니다"
        옆의 [그래도 열기] 클릭 → 비밀번호 → [열기]
     → 이후부터는 그냥 더블클릭하면 바로 열립니다.

   ※ 앱이 안 열리면 같은 폴더의 「배너 생성기.command」를 대신
     우클릭 → 열기 하셔도 똑같이 동작합니다.
   ※ "손상되었기 때문에 열 수 없습니다"라고 뜨면 옛날 버전입니다.
     Drive에서 「OGQ 배너 생성기.zip」을 다시 받아주세요.

3. 사용
   검은 터미널 창이 뜨면 둘 중 하나를 하고 Enter:
   ① OGQ마켓 판매 링크 붙여넣기
      예) https://ogqmarket.naver.com/artworks/sticker/detail?artworkId=61bc52a6358f4
   ② 스티커 원본 zip 파일을 검은 창 위로 끌어다 놓기
      (main/tab/1~24.png 들어있는 원본 패키지)

   이어서 "출시일"을 물어보면 SNS 홍보 이미지에 들어갈 날짜를
   입력하세요 (예: 8월 19일). 비우고 Enter 치면 날짜 없이 만듭니다.

   30초~1분 후 배너 9종 + SNS 홍보 이미지 2종이 생성되고 결과 폴더가 자동으로 열립니다.
   ※ 첫 실행은 구성요소 자동 설치 때문에 1~2분 더 걸릴 수 있어요.
   ※ Python이 없는 Mac이면 "명령어 라인 도구" 설치 창이 뜹니다.
      [설치]를 누르고 끝나면 다시 실행해 주세요. (한 번만)

4. 결과물 저장 위치
   - 프로그램 폴더 안 output/<작품명>/ 폴더
   - Google Drive 데스크톱 앱을 쓰는 경우:
     공유 드라이브 > 112_운영팀 > 08.기타 자료 > Ai개발 > <작품명> 배너
     폴더에도 자동 저장됩니다.

[참고]
- 배너는 실행할 때마다 색상·배경·배치가 매번 다르게 생성됩니다.
  마음에 안 들면 같은 링크로 다시 돌리면 새 디자인이 나옵니다.
- 모든 배너는 텍스트 없이 스티커 이미지로만 구성됩니다.
- 문제가 있으면 개발 담당자에게 문의해 주세요.

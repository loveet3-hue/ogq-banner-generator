OGQ 운영팀 도구

🎨 OGQ 콘텐츠 생성기 가이드

스티커 판매 링크 하나로 플랫폼 배너 9종 + SNS 홍보 이미지 2종을, 인터뷰 엑셀 하나로 인스타 카드뉴스를 자동으로 만드는 웹 도구입니다. 설치도, 로그인도 필요 없습니다. Windows / Mac 모두 사용 가능.

ogq-banner.streamlit.app ← 브라우저 주소창에 입력하거나 클릭. 즐겨찾기 추천!

⏰ 한동안 아무도 안 쓰면 서버가 잠들어요. 첫 화면에 "Zzzz… get this app back up" 버튼이 보이면 눌러주고 30초쯤 기다리면 됩니다.

탭 1

🖼 배너 생성기

  1. 소스 선택 — 둘 중 편한 방법으로:
    · OGQ마켓 링크: 판매 페이지 주소를 붙여넣기
    · 스티커 원본 zip 업로드: 원본 패키지(main/tab/1~24.png)를 올리기 (더 선명함)
  2. 출시일 입력 — SNS 홍보 이미지의 하단 문구가 됩니다. 예: 8월 19일 (비우면 "NEW 출시!")
  3. ✨ 배너 만들기 클릭 → 30초~1분 대기
  4. 미리보기 확인 후 ⬇️ 배너 전체 다운로드 (zip)
마음에 안 들면? 「배너 만들기」를 다시 누르세요. 배경·색·배치가 매번 새로운 조합으로 나옵니다. 「시안 개수」를 2~3으로 올리면 한 번에 여러 시안이 나와요.

✏️ 배너 편집

배너 생성 후 아래 배너 편집에서 수정할 배너를 고르면 편집 화면이 열립니다.

스티커 옮기기 / 크기 / 회전드래그 · 모서리 핸들 끌기
스티커 일부만 남기기 (글자 떼기)스티커 클릭 → ✂ 자르기 → 남길 영역 지정 → 적용
부분만 지우기스티커 클릭 → ◌ 지우개 → 문지르기 → 지우개 끝
글자 수정글자를 더블클릭해서 타이핑 (폰트·색·테두리 변경 가능)
글자 추가＋ 텍스트
스티커 추가화면 아래 스티커 목록에서 클릭
실수했을 때↶ 실행취소 또는 처음으로
저장⬇ PNG 다운로드 — 원본 해상도로 저장됩니다
주의: 편집한 결과는 「전체 다운로드 zip」에 포함되지 않아요. 편집한 배너는 꼭 PNG 다운로드 버튼으로 따로 저장하세요.
탭 2

📰 인터뷰 카드뉴스

  1. 네이버 폼 → 응답 → 엑셀(.xlsx) 다운로드 한 파일을 그대로 업로드
    처음이라면 「샘플 데이터로 먼저 테스트해보기」를 켜서 체험해보세요
  2. 옵션 선택 — 월, 카드 규격(정사각 1:1 / 세로 4:5), 배경 테마(auto 추천), 응답자(전체 또는 1명)
  3. 📰 카드뉴스 만들기 클릭
  4. 크리에이터별로 표지 + Q&A 카드 + 인스타 캡션 + 블로그 글이 생성됩니다 → 전체 zip 다운로드
자동으로 되는 것: 엑셀 응답에 OGQ마켓 링크가 있으면 크리에이터 이름과 캐릭터 이미지를 알아서 찾아 넣고, 크리에이터마다 다른 파스텔 테마를 배정합니다.

🙋 자주 묻는 질문

화면이 안 열리고 "Zzzz" 라고 나와요
서버가 자는 중이에요. 파란 버튼을 누르고 30초 기다리면 켜집니다.
카드뉴스 첫 생성이 유난히 오래 걸려요
서버가 깨어난 직후 첫 1회는 렌더링 엔진을 준비하느라 1~2분 더 걸립니다. 그 다음부터는 빨라요.
디자인이 마음에 안 들어요
만들기 버튼을 다시 누르면 완전히 새로운 디자인이 나옵니다. 몇 번 돌려서 고르시고, 세부 수정은 ✏️ 편집에서.
업로드한 파일은 어디에 저장되나요?
서버에 남지 않습니다. 생성이 끝나면 다운로드한 zip만 내 컴퓨터에 남아요.
인터넷 없이 / Mac 앱으로 쓰고 싶어요
